# Showcase — SaaS Auth Dashboard Demo

## O que este projeto mostra

Demo pública para apresentar cadastro, login, dashboard e logout em um shell SaaS.

## Status desta rodada

- Validado em 26/07/2026: testes, lint, build e auditoria de dependências
- Demo publica: https://saas-auth-dashboard-demo.vercel.app
- GitHub: https://github.com/Beckerr11/saas-auth-dashboard-demo
- Limite: autenticação, provedores, contas e tokens são simulados no navegador.

## Materiais desta pasta

- `video-script.md` - roteiro curto de apresentacao
- `scenes.md` - ordem de cenas para gravacao
- `captions.md` - textos de apoio para video, reels ou post
- `screenshots/login-desktop.png` — login em 1440 × 900
- `screenshots/dashboard-desktop.png` — dashboard em 1440 × 900
- `screenshots/login-mobile.png` — login em 390 × 844

## Como usar

1. Rode a demo local ou abra a deploy publica.
2. Siga o roteiro de video.
3. Use as capturas versionadas como referência do SHA validado.
4. Grave o vídeo somente quando existir um arquivo ou link público verificável.
