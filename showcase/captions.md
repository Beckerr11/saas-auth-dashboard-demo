# Legendas — SaaS Auth Dashboard Demo

- Projeto: SaaS Auth Dashboard Demo
- Problema: apresentar cadastro, login, dashboard e logout sem infraestrutura externa.
- Solução: contas, sessão e provedores simulados no navegador.
- Stack: React, Vite, React Router e `localStorage`
- Limite: não é autenticação segura e não protege dados reais.
- Status: validado em 26/07/2026
- Demo: https://saas-auth-dashboard-demo.vercel.app
- GitHub: https://github.com/Beckerr11/saas-auth-dashboard-demo
